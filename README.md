# math-slides
数学の授業スライド（HTML）。GitHub Pages で公開: https://kitaba417.github.io/math-slides/
- sanheiho/ … 三平方の定理の利用（254〜269 解説）
- ichiji/ … 中1 1次関数（01〜11、02b は変化の割合の補助）
- futoushiki/ … 数学Ⅰ 1次不等式（中3先取り, 01〜04）
- config.json … 目次・表示設定（admin.html の管理画面から編集。手で直すときは先に pull）
- manifest.json … 各スライドのページ題名一覧（管理画面のページ表示切替用）
