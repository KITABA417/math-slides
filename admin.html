スライド管理画面

先生用（全部見られる一覧）: sensei-ea03647e/
学年ページに出すスライド・ページの表示／非表示と、表記（題名・説明）を変えられます。変更したら下の「保存して公開」を押してください。生徒の画面には1〜2分ほどで反映されます。

合い言葉（GitHub のトークン）

トークンの作り方（最初の1回だけ）
  1. GitHub にログインした状態で トークン作成ページ を開く。
  2. Token name に「スライド管理」など好きな名前、Expiration（有効期限）は 1 年など長めを選ぶ。
  3. Repository access で Only select repositories を選び、math-slides を選ぶ。
  4. Permissions の Contents を Read and write にする。
  5. 一番下の Generate token を押し、表示された文字列（github_pat_…）をコピーして上の欄に貼り、「登録」。
トークンはこのブラウザの中だけに保存され、ほかの人には見えません。別の端末で管理するときは、その端末でもう一度登録してください。
